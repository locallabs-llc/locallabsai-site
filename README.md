# locallabsai.com

Static website for Local Labs LLC, served by GitHub Pages at https://locallabsai.com.

- Edit page content in `_src/*.html` (body only); header, footer and nav live in `build.py`.
- Run `python3 build.py`, then commit and push. Pages redeploys in about a minute.
- No JavaScript, cookies, analytics or third-party requests — keep it that way (the privacy policy says so).
